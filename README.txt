MB 1843AE 遊覽車模擬器 v1.0

這是完全重做的 3D 原型。

部署到 GitHub Pages：
1. 把 index.html 上傳到 Repository 根目錄。
2. GitHub → Settings → Pages。
3. Source 選 Deploy from a branch。
4. Branch 選 main，資料夾選 /(root)。
5. Save，等 GitHub Pages 產生網址。
6. 用 iPhone Safari 開網址，橫向遊玩。

操作：
- 左下搖桿：人物移動
- 直接拖曳遊戲畫面：轉視角
- 走到遊覽車右前門旁 → 開前門
- 用搖桿真正走上階梯進車內
- 走到駕駛座旁 → 坐進駕駛座
- 啟動引擎 → 放氣壓手煞車 → 進檔 → 油門
