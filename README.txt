億家設計遊戲 v3 — 創世神操作版

請把以下 3 個檔案上傳到 GitHub Repository 根目錄並覆蓋舊檔：
- index.html
- manifest.webmanifest
- sw.js

主要操作：
- 左下虛擬搖桿：移動
- 右半畫面滑動：轉視角
- 跳：跳躍
- 放置：在準星位置放置目前材料
- 拆除：拆除準星瞄準的物件
- 底部快捷欄：地板 / 牆 / 門 / 窗 / 道路 / 軌道
- 自動存檔：每次放置或拆除後自動儲存

如果更新 GitHub Pages 後還看到舊版：
1. Safari 強制重新整理
2. 關閉舊分頁再重開
3. 如果已加入主畫面，先移除，再重新加入主畫面
